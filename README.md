## 🚀 Introduction

**li** is a lightweight **GitHub Webhook** + **Telegram Bot** notification system. It allows you to:

- 📨 Send **GitHub-style notifications** to Telegram
- 🔗 Share **introduction links** via Telegram bot
- 📝 Collect **contact information** (Age, Telegram, Instagram, Message)
- 🔔 Get **real-time notifications** when someone submits the form
